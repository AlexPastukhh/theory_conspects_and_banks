# Conspect folder naming rule

```text
conspect folder name = exact source SVG filename without `.svg`
```

Examples:

```text
websockets.svg    -> _ai-conspects/websockets
imemorycache.svg  -> _ai-conspects/imemorycache
jsonconverter.svg -> _ai-conspects/jsonconverter
```

Related duplicate-upload filenames such as `name(1).svg` and `name(2).svg` belong to `_ai-conspects/name` when they are parts/copies of the same source conspect.
