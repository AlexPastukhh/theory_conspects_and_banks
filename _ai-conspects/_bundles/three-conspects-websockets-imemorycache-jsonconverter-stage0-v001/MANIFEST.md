# Three-conspect stage0 bundle — naming correction v002

Included conspect folders are named exactly after their source SVG stems:

- `websockets.svg` -> `_ai-conspects/websockets`
- `imemorycache.svg` -> `_ai-conspects/imemorycache`
- `jsonconverter.svg` -> `_ai-conspects/jsonconverter`

## Naming rule

Use the source SVG filename exactly, without the `.svg` extension.

For related uploads that differ only by an automatic copy suffix such as `name(1).svg`, `name(2).svg`, group them under the base source name `name` instead of creating separate numbered conspects.

Each conspect folder contains its source SVG, extracted images, inventories, contact sheets, region candidates, ledger, and current source of truth.
