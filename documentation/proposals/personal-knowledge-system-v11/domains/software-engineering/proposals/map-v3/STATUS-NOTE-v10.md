# Map v3 status under system v10

Software Engineering Map v3 remains the current best **Area/Subarea taxonomy proposal**.

Its section proposing multiple cross-cutting logical views predates the simplified system-level view model adopted in the v10 working state.

Current system rule:

```text
Core views
├── Coverage & Expansion View
├── Expansion Plan
└── Repetition View
```

Quality attributes, performance, reliability, technology, tags, and comparison discovery remain useful dimensions, but default to tags/filters/ordinary navigation unless a future concrete use case justifies a dedicated maintained view.

This note supersedes only the **view-layer recommendation** inside Map v3. It does not supersede the 15-Area taxonomy or the Subarea/audit work.
