# UC-KNOWLEDGE-MATERIALIZE-SOURCE — Materialize Source Into Knowledge

## Situation
An authoritative source corpus or prepared source conspect contains meaningful learning content that should be fully and accountably reflected in the knowledge layer.

## Result
Every meaningful claim in the selected source scope receives an explicit disposition, for example:
- mapped to existing knowledge;
- merged into another Concept/Knowledge Unit;
- created as new knowledge;
- marked non-learning;
- left unresolved.

No-loss is supported by semantic review, not registry counts alone.

## Process
1. Fix authoritative source scope.
2. Build meaningful claim inventory at appropriate granularity.
3. Determine semantic destinations.
4. Find duplicates/overlaps.
5. Assign disposition to each meaningful claim.
6. Integrate verified knowledge through the shared process.
7. Preserve provenance.
8. Review semantic coverage.
9. For visual sources, also review visual/region boundaries.
10. Do not treat registry existence/count equality as proof of completeness.

## Boundary
This Use Case is for accountable materialization of a source corpus. A small isolated Question does not need the heavyweight no-loss workflow.
