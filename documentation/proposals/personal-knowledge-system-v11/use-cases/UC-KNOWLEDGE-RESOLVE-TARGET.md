# UC-KNOWLEDGE-RESOLVE-TARGET — Resolve Knowledge Target

## Situation
A concrete target has already been selected: a Question, a gap, a bounded part of an Area, an unknown mechanism, or a model needing clarification.

A special comparative or practice-based result is not the primary goal.

## Result
The target is resolved to the depth justified by priority and available evidence:
- uncertainty is materially reduced;
- a coherent mental model is formed;
- durable knowledge is integrated;
- or the target is explicitly left unresolved when evidence is insufficient.

## Process
1. Clarify target scope.
2. Identify what is already known.
3. Determine required depth from the Priority Model.
4. Research appropriate sources.
5. Distinguish established facts, interpretation, disagreement, and uncertainty.
6. Build a coherent mental model.
7. Integrate durable knowledge through the shared integration process.
8. Link it to neighboring Concepts/Knowledge Units.
9. Route newly created Questions back to expansion planning.

## Boundary
Use a specialized Use Case when the independently useful result is:
- a comparative model → `UC-KNOWLEDGE-EXPAND-BY-ANALOGY`;
- evidence from application → `UC-KNOWLEDGE-EXPAND-BY-PRACTICE`;
- accountable whole-source transfer → `UC-KNOWLEDGE-MATERIALIZE-SOURCE`.
