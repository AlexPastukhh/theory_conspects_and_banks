# UC-KNOWLEDGE-EXPLAIN-PERSONAL-MODEL — Explain Through Personal Knowledge Model

## Situation
The owner wants to understand, reconstruct, discuss, or explain a topic using the way it is already organized in the personal knowledge base.

## Result
An explanation or reasoning path that:
- follows the owner's useful structure and terminology;
- uses personal analogies and mental models where helpful;
- preserves the owner's convenient route to understanding;
- distinguishes personal shorthand from formal/current claims;
- corrects inaccuracies when necessary.

## Process
1. Find the relevant personal knowledge.
2. Recover the formal model, personal model, examples, and caveats.
3. Use the personal representation as the main explanatory path.
4. Verify factual/current claims when necessary.
5. Make limits of analogies and simplifications explicit.
6. Route newly exposed gaps/questions to expansion planning.

## Boundary
The value is not that AI needs local notes to know public facts.
It is that the assistant can work through the topic in the owner's own representation.
